# 📔 Jurnal Mental Health

Aplikasi Android sederhana untuk menulis jurnal harian dan merefleksikan perasaanmu, kapan saja dan di mana saja.

![Platform](https://img.shields.io/badge/platform-Android-green)
![Versi](https://img.shields.io/badge/versi-v1.0.0-blue)
![Lisensi](https://img.shields.io/badge/lisensi-MIT-lightgrey)

## ✨ Fitur

- Tulis jurnal harian dengan tampilan yang bersih dan nyaman
- Catat suasana hati dan perasaanmu
- Animasi halus yang menenangkan
- Ringan dan mudah digunakan
- Data tersimpan di perangkatmu

> Tambahkan atau sesuaikan daftar fitur di atas dengan fitur aplikasi yang sebenarnya.

## 📲 Download & Instalasi

1. Buka halaman [**Releases**](../../releases/latest) di repo ini.
2. Unduh file `JurnalMentalHealth-v1.0.0.apk`.
3. Buka file APK di HP Android kamu.
4. Jika diminta, izinkan **"Instal dari sumber tidak dikenal"** untuk browser atau file manager yang kamu pakai.
5. Ketuk **Instal**, lalu buka aplikasinya.

**Persyaratan:** Android 5.0 (Lollipop) ke atas.

## 🔐 Verifikasi APK (opsional)

APK ini ditandatangani dengan keystore pribadi pengembang. Kamu bisa mencocokkan checksum SHA-256 file yang diunduh dengan yang tertera di halaman Release.

## 🛠️ Teknologi
